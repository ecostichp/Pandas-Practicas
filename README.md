## Instrucciones

Para correr este código, abre Windows PowerShell o una terminal y sigue los siguientes pasos:


### 1. Actualiza PIP en python.
```
python -m pip install -U Pip  
```

### 2. Crea un entorno para este proyecto y actívalo.
Dentro la carpeta raiz corre el siguiente código:
```
python -m venv env_pandas_practicas
env_pandas_practicas\Scripts\activate
```

### 3. Actualiza PIP dentro del entorno e instala las dependencias del proyecto.
```
python -m pip install -U Pip
python -m pip install Pandas SQLAlchemy iPyKernel OpenPyXL Seaborn iPyChart iPyWidgets ReportLab
```
